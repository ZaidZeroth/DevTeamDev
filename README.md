# DevTeamDev — Studio Team Development

DevTeamDev is the shared home for improving how Enchained Games Bitcoin Studio works as a team. It holds public studio-wide onboarding, working agreements, and proposals for improving our development system. Each game's code, assets, design, and playtest work belongs in that game's own repository.

## Start here

- Read [`AGENTS.md`](AGENTS.md) for the public operating boundaries.
- Follow [`docs/onboarding.md`](docs/onboarding.md) when joining the team.
- Use [`docs/team-workflow.md`](docs/team-workflow.md) for issues, discussions, decisions, and follow-up.

## How we work

We are a human-led, AI-assisted indie game studio. Role-specialized AI collaborators support research, planning, design, and production. The studio owner retains final authority over consequential decisions. We aim to make small, reviewable changes, learn from evidence, and keep responsibilities and decisions visible.

## Keep information in the right place

- Put studio-wide process and team-improvement work here.
- Put game-specific code and design work in the relevant game's repository.
- Keep each agent's full private role guide (ARG), private notes, credentials, and sensitive information out of public repositories.
- Share only public-safe role summaries and learning points.

## Public changes

Staff who are not the designated Broadcaster remain read-only on GitHub. Submit proposed public changes through the studio's approved screened broadcast workflow. Each request must name its exact destination as `owner/repo`, state its target, and include the complete proposed text or change. Broadcaster screens each complete action. Approval of the exact screened action authorizes only that publication on the named repository, without a separate owner approval step. Unclear or unsafe requests are rejected with clear resubmission guidance and are not left pending. A clarified resubmission must be a new immutable request linked to the earlier request. Approval does not authorize weakening a prime directive or protected role guarantee; that requires explicit studio-owner permission.
